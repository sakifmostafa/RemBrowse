Questions.

What is RemBrowse?

RemBrowse is a minimal, tiled web browser for Android laptops (Googlebook OS) and Android devices. It is built on Mozilla GeckoView, Firefox's engine, and shows up to four pages side by side in one window.

Is RemBrowse free?

Yes. RemBrowse is free to download. There is no RemBrowse account, sync, analytics or crash reporting, and nothing you browse is sent to us.

Which devices does RemBrowse run on?

Any Android device running Android 8.0 or later: phones, tablets and laptops. It is made for Googlebook, where the split view and keyboard shortcuts shine. Pick the Intel or AMD (x86_64) download for most Android laptops, or ARM (arm64-v8a) for phones, tablets and ARM laptops.

Can I use Firefox add-ons in RemBrowse?

Yes. RemBrowse runs real Firefox add-ons. Browse and install them from Firefox Add-ons in Settings, such as Bitwarden, SponsorBlock and Dark Reader. uBlock Origin is set up on first launch to block ads, and you can switch it off or remove it in Settings.

How do I install the APK safely, and how do updates work?

Download the file for your processor on the device itself and open it. If Android asks, let your browser install apps. Each download shows its SHA-256, and every release since 0.09 is signed with the same key, so you can check the file against the fingerprint under Check a download. After that RemBrowse keeps itself up to date: it checks a new version's size and SHA-256, then hands it to Android's installer, and your tabs stay put.

RemBrowse is built on Mozilla GeckoView and runs Firefox add-ons from addons.mozilla.org. Requires Android 8.0 or later. Ad blocking by uBlock Origin, which can be switched off or removed in Settings.
