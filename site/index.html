What it does

A laptop browser, on Android

Android laptops deserve more than a stretched phone browser. RemBrowse has one quiet toolbar, a tab rail on the left, and the things you reach for on a real computer.

Real Firefox add-ons

Install uBlock Origin, Bitwarden, SponsorBlock and the rest straight from Firefox Add-ons, or a signed .xpi from a file. AdGuard blocks ads from the first launch, and you can switch it off at any time. Extension buttons sit in the tab rail, and their popups open at full size.

An SSH terminal in a tab

Open a terminal like any other tab and keep it beside your pages. Save hosts, generate or import keys, and sign in to Tailscale SSH. Passwords and keys are sealed by the device's keystore.

Keyboard first

A command palette for tabs, addresses and commands, and the shortcuts you already know from desktop browsers.

  • CtrlKCommand palette
  • CtrlGGo to address
  • CtrlFFind in page
  • CtrlTNew tab
  • Ctrl\Split view
  • CtrlHHistory

On a phone, too

In a narrow window the tab rail folds away and two pages stack, each with its own divider. The same tabs, layouts and add-ons, sized for one hand.

Feels like a desktop

Right-click links and pictures with the touchpad, scroll with two fingers, see hover states and resize cursors, and resize the window freely.

Private by default

Tracking protection that doesn't break sites, no cloud backup of your browsing profile, and history that stays on the device.

Install it

  1. Download the file for your processor, on the device itself.
  2. Open it. If Android asks, let your browser install apps (it asks once).
  3. Tap Install. From then on RemBrowse keeps itself up to date: Settings → About.

Using 0.13.7 or older? Its update check looks somewhere that is closed now, so install this version by hand once. It installs over the old one and keeps your tabs and settings.

Coming from 0.08 or older? Those were signed with a different key. Uninstall them first; this removes their tabs, bookmarks and extensions.

Check a download

Each file's SHA-256 is shown on its card. Every release since 0.09 is signed with the same key, whose certificate has this SHA-256 fingerprint:

F1:A5:30:6A:47:E4:BE:78:AD:7F:B0:C1:41:88:71:E3:A6:C9:A8:35:13:49:E2:42:39:DB:20:B4:75:B2:BE:06

To check it on a computer with the Android SDK:

apksigner verify --print-certs RemBrowse-x86_64.apk
